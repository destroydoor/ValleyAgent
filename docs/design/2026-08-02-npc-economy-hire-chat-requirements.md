# NPC 经济 / 雇佣 / 聊天栏沟通 — 需求文档

> **日期**：2026-08-02
> **状态**：需求已拍板，技术方案未定（本文档只定义"做什么"和"体验什么样"，不定义实现）
> **上游**：`AGENTS.md` §1.2 核心目标（P1 社会存在）、§10 路线图 P1
> **已拍板的设计决策**（2026-08-02 与设计讨论记录）：
> 1. 定价浮动率按 NPC 精明度逐人配置（皮埃尔 ±5%、莱纳斯 ±50% 这类差异是允许的），但必须有**购买力约束**——NPC 会考虑自己的经济能力，太贵买不起 / 不愿掏空积蓄
> 2. NPC 求购（双向经济）进第一版
> 3. 高好感雇佣可以有朋友价甚至免费
> 4. NPC 主动发言默认**每人每日 ≤2 条**（可配置）；玩家接话后进入会话模式，会话期间的来回不计入主动额度

---

## 0. 设计定位

这批需求补的是 NPC 的**社会存在感**：现在的 NPC 有情绪有记忆，但没有钱、没有体力节奏、没有低摩擦沟通渠道，像个"会说话的宠物"而不是"镇上的人"。三条原则贯穿全文：

- **人设即玩法**：交易、雇佣、发言频率的差异全部来自人设差异，玩家"摸透每个 NPC 的脾气"就是核心乐趣，而不是背一条全局公式。
- **防坑是底线不是玩法**：价格公式只负责防止玩家把 NPC 骗到破产，讲价空间必须在底线之内由人格产生。
- **频率比内容重要**：所有 NPC 主动行为（发言、求购）宁可少而准，不可多而吵。

## 1. NPC 经济系统

### 1.1 钱包与背包

- 每个 NPC 有**钱包**（金币数）和**背包**（物品列表，即现有 AgentInventory 的经济化扩展）。
- 初始资金/物品由**导演**在叙事编排时分配，符合人设（格斯开酒吧手头宽裕，莱纳斯身无分文）。
- 钱的流转必须闭环：
  - 流入：玩家购买 NPC 的物品、雇佣报酬、导演剧情注入
  - 流出：NPC 购买玩家的物品、送礼、导演剧情消耗
- 没有流出端的钱包是死循环，迟早变成"全镇提款机"——所以 §1.5 的 NPC 求购是必需项，不是可选项。

### 1.2 定价双层模型

**认知层（防坑底线）**：

```
公道价 = 物品的系统卖价（玩家卖给商店的价格）
NPC 心理价区间 = 公道价 × (1 ± 精明度浮动率)
```

- 精明度浮动率**逐 NPC 配置**，示例：皮埃尔 ±5%（精明商人）、格斯 ±10%、玛妮 ±15%、莱纳斯 ±50%（对钱没概念）。
- 玩家报价超出 NPC 心理价区间 → NPC 警觉。精明 NPC（皮埃尔类）："你当我冤大头？"，掉好感；老实 NPC（玛妮/莱纳斯类）：含糊拒绝但不记仇。
- 该浮动率就是"物品大概价格 = 系统价 ±10%"需求的落地：默认值 10% 可配置，逐 NPC 覆盖。

**人格层（玩法空间）**：

- 在心理价区间**以内**，NPC 的实际出价由人设决定：
  - **精明度**：还价时让多少。皮埃尔只让 3%，老实人让得多。
  - **需求偏好**：海莉对她想要的东西（石英、衣物类）愿意出到区间上限；NPC 对讨厌/无用的物品压到下限甚至拒收。
- 玩家的"会做生意"爽感来自摸清每个 NPC 的脾气，而非背公式。

### 1.3 购买力约束（防"玩家卖贵货 +50% 暴富"）

NPC 买玩家东西时，出价上限：

```
出价上限 = min(心理价, 钱包余额 × 预算比例)
```

- **预算比例**按人设分档（数值可配置）：谨慎型 30%（"这要花掉我小半积蓄了"）、普通 50%、豪爽/莱纳斯 80%。
- 单价 > 钱包余额 → 直接说"太贵了，我买不起"。
- 单价 > 钱包 × 预算比例 → "这几乎要花光我的钱了，不行。"（语气按人设：皮埃尔精明地拒绝，玛妮愧疚地拒绝）
- 效果：玩家向莱纳斯兜售一颗 5000g 的钻石，即使莱纳斯 ±50% 觉得值 7500g，他全部身家 80g 也只能说买不起。**价格认知和支付能力是两件事，NPC 两个都要有。**

### 1.4 阶梯式还价

- 还价最多 **3 轮**（可配置），NPC 让步幅度**逐轮减半**：
  - 例：NPC 开价 1000g，玩家砍 → 第 1 轮最多让到 900，第 2 轮最多让到 850，第 3 轮最多让到 825，之后"不能再低了，再低我宁愿不要"。
- 玩家出价低于 NPC 底线 → 本轮拒绝，耐心 -1。
- 连续谈崩 2 次 → 交易关闭，NPC 轻微不快（不影响好感，影响当天再谈的态度："今天不想跟你做生意了"）。
- **恶意低价**（低于公道价下限再低 50% 以上）→ 触发警觉反应（见 §1.2），精明 NPC 掉好感。
- 对话风格全程人设化：皮埃尔讨价还价像做生意，莱纳斯只会说"你看着给就行"。
- 反向（NPC 卖给玩家）对称：NPC 从区间上限开价，玩家砍，让步同样阶梯递减。

### 1.5 NPC 求购（双向经济闭环）

- NPC 会主动发布求购：格斯收食材、克林特收矿石、皮埃尔收农产品……求购内容贴人设。
- 求购价 = 公道价 × 1.0~1.1（可配置），比普通卖店略赚，给玩家一个种田之外的销路。
- 发布渠道：聊天栏（§3）、对话中主动提及、或导演编排进当日 beat。
- 频率受 §0 第三原则约束：求购是点缀，不是每日刷屏广告。

### 1.6 配置项清单（全部进 ModConfig / 数据文件，不写死）

| 配置 | 默认 | 说明 |
|---|---|---|
| 精明度浮动率 | 0.10 | 逐 NPC 可覆盖（数据文件） |
| 预算比例 | 0.5 | 谨慎 0.3 / 普通 0.5 / 豪爽 0.8，逐 NPC 可覆盖 |
| 还价最大轮数 | 3 | — |
| 让步衰减 | 0.5 | 每轮让步幅度 ×0.5 |
| 恶意低价阈值 | 低于公道价下限 50% | 触发警觉的分界线 |
| 求购加价率 | 1.0~1.1 | NPC 求购出价系数 |
| 初始资金表 | 按人设 | 导演分配，数据文件配置 |

### 1.7 体验剧本

- **顺利交易**：玩家向格斯兜售 10 个土豆 → 格斯按心理价中段开价 → 玩家接受 → 钱货两讫，格斯："好嘞，今晚的汤有着落了。"
- **阶梯讲价**：玩家向皮埃尔买种子，皮埃尔开 105g → 玩家砍 → 100 → 再砍 → 97 → 再砍 → "95，最低了，再低我宁可留着。" → 第 4 次砍价被干脆拒绝。
- **买不起**：玩家向莱纳斯兜售钻石 → 莱纳斯："很漂亮……但我全部钱也不够。你留着吧。"（好感不变，记忆 +1："农场主给我看过一颗很美的石头"）
- **恶意压价**：玩家向皮埃尔报价只有公道价 30% → 皮埃尔："你这是在开玩笑吗？"好感 -，当天拒绝再谈。
- **NPC 求购**：早上聊天栏，格斯："收 10 个土豆，出 1.1 倍价，有货的送来。"玩家送货 → 成交。

### 1.8 交互入口与成交保障（2026-08-02 拍板）

**数据归属**：钱包/背包数据全在 C#；TS/LLM 只负责"谈"，C# 负责"成交"。LLM 在聊天里答应的价格只是**意向**，成交瞬间的游戏状态才算数。

**交易入口（方案 A）**：持物品右键 Agent NPC → 小菜单"送礼 / 交易 / 取消"。仅 Agent NPC 生效，非 Agent 村民保持原版送礼逻辑。菜单同时防错：玩家明确选了"交易"，不存在"想谈价被当成送礼直接送掉"的事故，反之亦然。

**两个方向的流程**：
- **玩家卖**：持物品右键 → 选"交易" → NPC 表态要不要（人设+需求偏好）→ 开价 → 聊天阶梯还价 → 谈妥生成 pending offer → 玩家确认 → C# 原子校验成交。
- **玩家买**：聊天问"你有什么卖的"→ NPC 调工具打开只读背包界面（展示哪些由人设决定）→ 玩家点选物品 → NPC 开价 → 还价 → pending offer → 确认 → C# 校验成交（校验项互换：玩家金钱 + NPC 背包）。

**NPC 背包展示界面**：复用游戏自带箱子/背包界面，但必须**只读**——能看、能点选"我要买这个"进入谈价，**不能直接拖走**。界面层预留"展示模式"抽象，未来偷窃功能走独立入口复用它，而不是改这个界面。

**钱包透露是人设不是规则**：莱纳斯问就说，皮埃尔打太极（"够过日子，问这个干嘛？"），海莉看心情炫耀或哭穷。prompt 给人设指引，LLM 自由发挥，不硬编码允许/禁止。

**pending offer（待成交状态）**：每 NPC 同时最多 1 个；内容 = 物品 + 数量 + 谈妥价 + 有效期。默认 30 秒（可配置）；玩家走太远、切地图、超时 → 自动作废，NPC 吐槽一句（"人呢？不买了？"）。

**成交原子校验（C#，全部通过才动钱动货）**：
```
玩家背包里物品还在吗？数量够吗？
NPC 钱包余额够吗？（NPC 买入时）
玩家金钱够吗？（玩家买入时）
→ 全过：扣钱、转物品、写双方记忆、回 action_result（成功）
→ 任一不过：拒绝 + action_result.reason（复用已有反馈管道）
```
谈妥但成交失败时 NPC **知道原因**，会说"咦，东西呢？"而不是以为自己买到了——这是防"海莉式失忆"在经济系统里的重演。

### 1.9 验收标准

- 玩家无法用远超公道价的价格把物品卖给任何 NPC（价格认知约束生效）。
- 玩家无法掏空任何 NPC 的钱包（购买力约束生效），即使该 NPC 价格认知模糊（莱纳斯）。
- 同一物品向 3 个不同精明度的 NPC 兜售，得到 3 种明显不同的反应。
- 还价第 4 轮必被拒；连续谈崩 2 次当天交易关闭。
- 任一 NPC 钱包余额变化都有日志可查（见 §5）。

## 2. 雇佣系统

### 2.1 定位

雇佣 = **玩家花钱购买 NPC 的自主性配额**。嵌入导演编排框架：雇佣期是玩家向导演注入的**高优先级 beat**，期间 NPC 自主决策让位于契约；契约结束/完成，自主权归还 NPC。导演在雇佣期内不得插入与契约冲突的编排。

### 2.2 契约模型

- 契约内容：任务类型（跟随陪伴 / 收菜 / 挖矿 / 下矿保镖）+ 期限（半天 / 一天）+ 报酬。
- 计价：

```
报价 = 人设日薪基准 × 任务危险系数 × 缺钱修正 × 好感修正
```

  - 人设日薪基准：逐 NPC 数据配置（塞巴斯蒂安要价高态度拽，玛妮可能根本不接）。
  - 危险系数：保镖 > 挖矿 > 收菜 > 跟随。
  - **缺钱修正**：钱包低于阈值 → 更愿意接单甚至自降报价（"最近手头紧……行吧"）。
  - **好感修正**：朋友价折扣；close 以上可能免费。
- 讨价还价走 §1.4 同一套阶梯模型。

### 2.3 朋友价与"长工"保护

- 高好感 NPC 免费帮忙是允许的（已拍板）。
- 但免费被**频繁**使用（如一周内 3 次以上）触发人设吐槽事件："你总使唤我，把我当长工啊？"——这是免费的剧情素材，同时软性限制白嫖。

### 2.4 违约

- 玩家指派契约外任务（雇来当保镖却让去砍树）→ NPC 抗议（对话）："说好是护送你下矿的。"
- 玩家强行要求 → 好感下降，NPC 可单方面中止契约（报酬按完成度结算或拒收，按人设）。

### 2.5 体验剧本

- **缺钱接单**：玩家雇山姆当一天保镖 → 山姆钱包见底："800g？……行，成交，正好缺钱买琴弦。"
- **有钱拒绝**：玩家雇玛妮 → "我又不缺这个，你自己去吧，小心点。"（不伤人好感）
- **朋友价**：玩家雇阿比盖尔（close）下矿 → "跟我客气什么，走！"（免费；本周第 3 次时触发"长工"吐槽）
- **违约抗议**：雇来的保镖被指令去收菜 → "嘿，说好的保镖呢？"继续强行 → 契约中止，好感 -。

### 2.6 验收标准

- 同一雇佣请求，缺钱 NPC 与不差钱 NPC 反应明显不同。
- 雇佣期内 NPC 不被导演 beat 拽走（契约优先级高于常规编排）。
- 朋友价存在且有"长工"频率保护。
- 违约有抗议、强行有代价，报酬结算与契约状态一致。

## 3. 聊天栏双向沟通

### 3.1 玩家 → NPC

- 玩家在聊天栏直接打字即视为对**在场/跟随中**的 NPC 说话，NPC 异步回应，不强制开对话框。
- 不在场的 NPC 听不到普通聊天；唯一的远程通道是 §3.4 的喊话频道。

### 3.1.1 多 NPC 消歧（2026-08-02 拍板）

路由优先级（玩家一句话发给谁）：

1. **名字提及**：句子含 NPC 名字/昵称 → 路由给该 NPC。最优先，永远有效。
2. **当前会话**：有进行中的会话模式 → 继续路由给会话对象。
3. **跟随者/雇佣者**：跟着玩家的 NPC 是默认倾听者。
4. **最近交互 + 距离**：30 秒内交互过且在附近（~8 格）；再不行 → 最近的在场 NPC。

**沉默权**：路由命中 ≠ 必须回。内容明显不是对话（自言自语、骂怪物）→ 不接话。群体称呼（"你们""大家"）→ 附近 NPC 按话痨度最多 1~2 个接话，其余沉默，防刷屏。

**明确不做**：每句话广播给所有在场 NPC 各自 LLM 判断是否接话——Token 翻 N 倍且必然抢话。路由是确定性规则（便宜），接不接才是智能（贵，只花在路由命中的那个身上）。

### 3.2 NPC → 玩家（主动发言）

- 每个 NPC 有**话痨度**参数（0~1，逐人设配置：海莉高、塞巴斯蒂安极低）。
- **主动发言上限：默认每人每日 ≤2 条**（可配置）。
- 触发：场景事件驱动（玩家大批收获、下暴雨、玩家残血、节日前夕、玩家经过 NPC 身边等）+ 硬冷却。不允许无触发纯定时刷屏。
- **会话模式**：NPC 主动发言后玩家接话，双方进入会话；会话期间的来回**不计入**主动额度。玩家 60 秒（可配置）未回应 → 退出会话模式。
- 内容原则：宁可一天两句恰到好处的，不要每分钟一句废话。

### 3.3 长文本规则

- ≤1 句话：可走头顶气泡。
- >1 句话：**不进气泡**；全文进聊天栏。若需分段表现，按句切分、间隔弹出（间隔可配置），不允许一坨长文一次性糊进气泡。

### 3.4 晨间喊话（远程频道，2026-08-02 拍板新增）

玩家在聊天栏"喊话"（无 NPC 在场、或显式喊名字）时，消息远程路由到对应 NPC。这是**山谷里的公开行为**，不是私信系统——正因为是"喊"，时段和作息才成为设计的一部分。

**路由**：确定性规则优先，路由 Agent/导演只做歧义兜底——名字提及 → 当前会话 → 跟随/雇佣者 → 已醒来且关系最近的 NPC；完全无指向且规则判不出时才调一次 LLM 决策。

**时段感知（灵魂设计）**：
- 每个 NPC 有作息表（起床时间，逐人设：威利/玛妮早起，海莉 9 点前别指望心情好）。
- 回应 = 人设 × 当前时间 × 关系。6:30 被喊的海莉会烦（"……才六点半。你最好有重要的事。"），但**不掉好感**——吐槽是风味，惩罚不是。
- NPC 没醒或在忙**可以不回**。沉默本身就是人设：对空山谷喊话没人理，反而真实。

**记忆联动**：连续清晨骚扰写入 NPC 记忆（"他连着三天六点把我吵醒"）→ 回应逐日升级，白天碰面可能翻旧账。比数值惩罚更有威慑力，且完全符合记忆驱动行为的架构。

**拟真细节**：回应带几秒延迟（不是心灵感应秒回）；回应可带 NPC 自身状态/位置（"我还在睡觉！"）。

**额度豁免**：喊话的回应是**被动回应**，不占 §3.2 每人每日主动发言额度（与会话模式豁免逻辑一致）。

**剧本**：
- 6:30 玩家喊"海莉！"→ 几秒后："……才六点半。你最好有重要的事。"
- 6:30 玩家喊"威利，今天鱼怎么样"→ 威利（早起了）："早啊！潮位不错，带上竿子来。"
- 无指向喊"有人吗"→ 路由给已醒且关系最近的 NPC；都在睡 → 无人应答。
- 连续三天 6 点喊海莉 → 记忆 +1，第三天回应明显更烦，白天对话翻旧账。

**验收**：
- 名字提及 100% 路由正确；同一句喊话，6:30 与 10:00 的海莉回应明显不同。
- 未醒/忙碌 NPC 可不回应；喊话回应不占主动额度。
- 无指向喊话最多触发 1 次路由 LLM 调用，绝不广播全图。

### 3.5 体验剧本

- **低摩擦对话**：玩家在田里干活，聊天栏敲"海莉你看这批南瓜"→ 海莉（在场）回："哇，比我脸还大！"对话框全程没打开过。
- **主动发言**：暴雨天，聊天栏弹出文森特："打雷了！我不怕，就是……有点响。"（当日他的第 1 条主动发言）
- **会话模式**：玩家回了文森特一句 → 来回聊了 4 轮 → 均不计主动额度；玩家去挖矿 1 分钟没回 → 会话自动结束，之后文森特当日还剩 1 条主动额度。
- **长文本**：NPC 的三句话回复 → 聊天栏里按句间隔出现，头顶无气泡。

### 3.6 验收标准

- 不开对话框可完成完整多轮对话。
- 任何 NPC 当日主动发言 ≤ 配置上限；会话模式内对话不计额度；会话超时退出后额度恢复计数。
- 长回复绝不出现在气泡；分段出现间隔正确。
- 无触发场景下 NPC 不会定时刷屏。

### 3.7 消息分级与静默规则（2026-08-02 拍板）

聊天栏消息分三级，样式和用途严格区分：

| 级别 | 样式 | 用途 | 例 |
|---|---|---|---|
| NPC 发言 | NPC 专属彩色 | NPC 真正"说话"（主动发言、回应、喊话） | "这批南瓜比我脸还大！" |
| 系统消息 | **灰色斜体或灰色普通字** | 玩家必须知情、但不该由 NPC"说"出来的机械事件 | `*海莉离开了*` |
| 静默 | 不发消息 | 高频机械过程 | 跨图跟随旅行 |

**规则**：

1. **地图切换全程静默**：跟随中的跨图旅行禁止任何"我马上来"/"我到了"类播报——切图是高频操作，次次说话等于刷屏。跟随的可靠性靠动作本身表达（NPC 真的从入口走进来），不靠嘴。
2. **Agent 模式退出发系统消息**：NPC 被交还原版日程时，聊天栏发灰色字 `*XXX离开了*`。玩家需要知道"跟班下班了"，但这是机械状态变化，不该用 NPC 口吻说。
3. **失败也要灰色字，不要沉默**：跨图跟随**失败**（跟丢）时发灰色系统消息（如 `*海莉没跟上*`）——静默规则只保护"正常流程"，不掩盖异常；玩家必须能察觉跟丢了。
4. **AI 主动决策的离开仍是 NPC 发言**：如果 NPC 是**自己决定**不跟了（LLM/导演决策），那是叙事时刻，由 NPC 人设化地说出来（"我先回去了，店里还有事"），不走灰色系统字。区分标准：机械状态变化 → 系统消息；角色意愿表达 → NPC 发言。
5. 同类机械事件（契约开始/结束、pending offer 作废）是否发灰色字，实现时按同一标准裁决：玩家不知情会困惑 → 发；玩家能从画面直接看到 → 静默。

## 4. 动态速度

- 原则：**速度是距离的视觉表达**。跟随/行动中按与目标的距离分段调速：远处加速追上，近处减速同行。
- 动画帧率与移动速度**等比例缩放**（跑动动画配跑动速度）。
- 分段数值进配置（参考档位：>8 格 2×、3–8 格 1.5×、<3 格 1×）。
- **不做体力惩罚**：NPC 追玩家追到"疲惫"听起来真实，实际体验是跟随不可靠，与已验证的跟随口碑直接冲突。疲惫情绪保留给战斗/干活场景。

## 5. 全量留痕日志（原则级需求）

- 凡是 AI 做的决定，事后必须能回答"它当时为什么这么想"：NPC 决策的输入上下文与输出、对话全文、导演的编排思考、工具调用与执行回执、钱包/背包变动。
- 当前日志可用信息太少（看不到程序真实状态、看不到 NPC 思考）——本需求是**基础设施级**，卡住后续所有调试与"历史回顾"功能。
- 存储模型沿用 `docs/design/2026-08-01-memory-narrative-extensibility.md` 的 TranscriptStore 设计；日志分级、格式、轮转策略属技术方案，另行设计。

## 6. 明确不做（本期）

- **偷窃**（玩家偷 NPC / NPC 的察觉与后果）：是经济系统的暗面，等经济系统立住后再单独立项。注意 §1.8 的背包展示界面已为它预留"只读展示模式"接口。
- NPC 体力/疲惫影响移动（见 §4）。
- 私人远程通讯（电话/信件私信）：不做。**例外已开**：§3.4 晨间喊话频道（公开的、受作息约束的远程通道）。
- 多 Agent 联机支持：仍为 P3。
