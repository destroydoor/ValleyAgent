## 三、关键变更详情

### P0-3：RuleBasedDecisionEngine 集成

**问题**：`RuleBasedDecisionEngine` 已实现但从未被实例化，CircuitBreaker OPEN 时 NPC 直接跳过决策导致"植物化"。

**解决方案**：在 `EventHandlerInitializer.MakeDecisionsAsync` 中，CircuitBreaker OPEN 时改为调用规则引擎兜底。

**修改文件**：
- [EventHandlerInitializer.cs](file:///<REPO_ROOT>/src/ValleyAgent/Initialization/EventHandlerInitializer.cs)
  - CircuitBreaker OPEN 分支改为调用 `DecideByRules(agent)` + `ApplyRuleDecision(agent, result)`
  - 新增 `DecideByRules(agent)` 私有方法：构建 `RuleDecisionContext`（位置/血量/好感度/玩家距离/天气/附近对象/情绪/连续IDLE计数/当前状态）
  - 新增 `ApplyRuleDecision(agent, result)` 私有方法：同步决策到 Brain + 入队 `_pendingDecisions` + 记录决策
- [AgentTickLoop.cs](file:///<REPO_ROOT>/src/ValleyAgent/Core/AgentTickLoop.cs)
  - 新增 `GetConsecutiveIdleCount(npcName)` 公开方法，供 RuleBasedDecisionEngine 的 TALK 门控使用

**规则引擎优先级**（5 条规则）：
1. 紧急战斗（附近有怪物）
2. 生存模式（血量 < 30%）
3. 机会工作（附近有作物/石头/采集物）
4. 社交互动（玩家在附近 + 连续 IDLE 计数达标）
5. 默认空闲

### 测试体系重构：阶段 3.5 C# 严格静态分析（0 警告）

**问题**：ValleyAgent 主项目存在 14 个 CA1031 错误（捕获过于宽泛的异常）和 15 个 CA1063/CA1816 警告（Dispose 模式实现不正确），违反"静态检测器必须 0 报错 0 警告"的铁律。

**解决方案**：
1. CA1031 修复：将 `catch (Exception ex)` 改为捕获更具体的异常类型（如 InvalidOperationException、JsonException、IOException 等），对于可能抛出多种异常的场景使用多个 catch 块。绝对不使用 NoWarn 或 SuppressMessage 抑制。
2. CA1063/CA1816 修复：实现标准的 Dispose 模式（`Dispose(bool disposing)` + `GC.SuppressFinalize(this)`），添加 `_disposed` 字段防止重复释放。

**修改文件**：

CA1031 修复（14 个位置，11 个文件）：
- [DialogueStateManager.cs](file:///<REPO_ROOT>/src/ValleyAgent/Api/DialogueStateManager.cs) — `Exception` → `InvalidOperationException` + `ArgumentException`
- [AgentContextBuilder.cs](file:///<REPO_ROOT>/src/ValleyAgent/Context/AgentContextBuilder.cs) — 空 catch → `catch (InvalidOperationException)`
- [GMCMIntegration.cs](file:///<REPO_ROOT>/src/ValleyAgent/Config/GMCMIntegration.cs) — 空 catch → `catch (InvalidOperationException)`
- [AgentTickLoop.cs](file:///<REPO_ROOT>/src/ValleyAgent/Core/AgentTickLoop.cs) — 2 处 `Exception` → `InvalidOperationException`
- [ConsoleCommands.cs](file:///<REPO_ROOT>/src/ValleyAgent/Debug/ConsoleCommands.cs) — `Exception` → `InvalidOperationException` + `ArgumentException`
- [FriendshipSystem.cs](file:///<REPO_ROOT>/src/ValleyAgent/Friendship/FriendshipSystem.cs) — `Exception` → `InvalidOperationException` + `HttpRequestException` + `TaskCanceledException`
- [FightHandler.cs](file:///<REPO_ROOT>/src/ValleyAgent/Handlers/FightHandler.cs) — `Exception` → `InvalidOperationException`
- [SocialPagePatch.cs](file:///<REPO_ROOT>/src/ValleyAgent/Patches/SocialPagePatch.cs) — 2 处 `Exception` → `InvalidOperationException` + `ArgumentException`
- [GameSummaryLoader.cs](file:///<REPO_ROOT>/src/ValleyAgent/RAG/GameSummaryLoader.cs) — 3 处：`Exception` → `IOException`+`JsonException`+`UnauthorizedAccessException` / `JsonException`
